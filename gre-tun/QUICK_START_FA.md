# راهنمای کوتاه GRE Tunnel Manager

نسخه 0.2.0-dev **آزمایشی است**. نصب و به‌روزرسانی یک دستور ثابت دارند:

```bash
curl -fsSL https://raw.githubusercontent.com/smorad3363/assistant-vps/master/gre-tun/install.sh | sudo bash
```

برای باز کردن منو:

```bash
sudo gre-tun
```

این نسخه هنوز تونل واقعی را روی سرور عملیاتی فعال نمی‌کند. مدیریت تنظیمات و ذخیره آمار در آن توسعه یافته، اما اعمال GRE/NAT، محدودیت سرعت و بازگشت امن در سناریوهای واقعی هنوز تأیید نشده‌اند. لطفاً جایگزین تانل‌های فعال نکنید.
