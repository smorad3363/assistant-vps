# راه‌اندازی اولیه GRE Tunnel Manager

این نسخه فقط برای مشاهده منو، ثبت تنظیمات و تولید کد اتصال است و هنوز تونل واقعی راه‌اندازی نمی‌کند.

**دستور ثابت نصب و آپدیت پس از انتشار کامل فایل‌ها در گیت‌هاب:**

```bash
curl -fsSL https://raw.githubusercontent.com/smorad3363/assistant-vps/master/gre-tun/install.sh | sudo bash
```

برای اجرا `sudo gre-tun` و برای گزارش وضعیت `gre-tun status --json` را بزنید. اجرای برنامه روی سرور پرترافیک به‌عنوان جایگزین GRE موجود توصیه نمی‌شود. در برنامه نهایی، همین دستور نصب و آپدیت ثابت خواهد ماند و هیچ مهاجرت خودکاری از تنظیمات GRE یا Port Manager قبلی انجام نمی‌شود.
