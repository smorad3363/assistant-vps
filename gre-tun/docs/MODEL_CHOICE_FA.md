# انتخاب مدل برای ساخت این پروژه

در تصویر ارسالی دو گزینه دیده می‌شود: GPT-6 و GPT-5.6 Sol. برای همین پروژه، انتخاب پیشنهادی من **GPT-6 روی High** است؛ این پیشنهاد پروژه‌محور است، نه ادعای بنچمارک اختصاصی بین دو گزینه تصویر.

دلیل: بخش دشوار کار، هماهنگ‌کردن مسیر رفت‌وبرگشت، کنترل سرعت، آمار و برگشت امن تغییرات است. راهنمای رسمی OpenAI مدل Astra از خانواده GPT-6 را برای کارهای پیچیده معرفی می‌کند و High را برای کارهای دشوار چندمرحله‌ای مناسب می‌داند. خود تصویر فقط برچسب GPT-6 را نشان می‌دهد؛ از روی آن نگاشت قطعی به شناسه API را فرض نمی‌کنیم. اگر در تنظیمات شما همین دو نام وجود دارد، همان GPT-6 را با High انتخاب کنید.

GPT-5.6 Sol نیز می‌تواند این قرارداد را پیاده کند؛ صحت خروجی باید با آزمون‌ها سنجیده شود، نه صرفاً نام مدل. بسته هیچ dependency یا API خاص مدل ندارد. GPT-6 High انتخاب پیشنهادی برای شروع است؛ اجرای کد و آزمون‌ها به محیط فایل/ترمینال نیاز دارد. reasoning=High به‌تنهایی دسترسی شبکه، root یا VM ایجاد نمی‌کند.
