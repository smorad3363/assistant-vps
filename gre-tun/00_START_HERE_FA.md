# بسته نهایی ساخت GRE Tunnel Manager

نسخه قرارداد: **1.0.0** — تاریخ: **2026-10-17**

این بسته را به هوش مصنوعی دارای دسترسی به فایل و ترمینال بدهید و متن `PROMPT_FOR_AI.txt` را ارسال کنید. انتخاب پیشنهادی برای دو گزینه تصویر شما: **GPT-6 با reasoning روی High**. پروژه به مدل یا API هوش مصنوعی وابسته نیست.

## چه چیزی قرار است ساخته شود؟

یک ابزار سبک برای **نصب تازه** روی Ubuntu 22.04 و 24.04، با اجرای `gre-tun` و چهار گزینه ثابت:

```text
GRE Tunnel Manager

1) Create tunnel
2) Manage tunnels and ports
3) Test connection
4) Uninstall

0) Exit

Select:
```

- چند ایران و چند خارج، با تونل‌های مستقل؛ نصب روی هر دو طرف لازم است.
- ساخت و ویرایش تونل و پورت؛ تولید کد تنظیمات برای طرف مقابل، بدون دسترسی خودکار به SSH آن سرور.
- ورودی `5445:5454` یعنی پورت ورودی 5445 و پورت مقصد 5454؛ `443` یعنی هر دو 443؛ چند مورد با کاما.
- TCP، UDP یا هر دو، IP ورودی مشخص و IP مقصد مستقل؛ آدرس سر فیزیکی تونل با مقصد سرویس اشتباه نمی‌شود.
- نمایش حجم آپلود/دانلود/مجموع و میانگین سرعت در **۱ ساعت و ۲۴ ساعت گذشته**؛ سرعت لحظه‌ای جدا.
- محدودیت سرعت آپلود و دانلود هر نگاشت، برای مجموع اتصال‌های آن؛ TCP و UDP در حالت Both سقف مشترک دارند.
- تست محدود و گزارش کوتاه؛ بررسی خودکار تداخل پورت، SSH، آدرس داخلی و مسیر.
- حفظ داده ثبت‌شده پس از ریبوت، بازیابی تغییر ناموفق و حذف اجزای متعلق به خود برنامه.
- تمام متن‌های برنامه، کد، کامنت‌ها، خروجی‌ها و لاگ‌ها انگلیسی هستند. فقط راهنمای کاربر این بسته فارسی است.

## نحوه تحویل به هوش مصنوعی

1. ZIP را در یک پروژه خالی باز کنید یا همان ZIP را پیوست کنید.
2. مدل انتخابی را روی High بگذارید و محتوای `PROMPT_FOR_AI.txt` را بفرستید.
3. AI باید سندها را بخواند، برنامه کامل را بسازد و آزمون‌ها را اجرا کند؛ صرفاً دوباره نقشه راه ننویسد.
4. آزمون شبکه باید در محیط آزمایشی انجام شود. اگر محیط لازم موجود نیست، نتیجه باید صریحاً `NOT RUN` باشد؛ موفقیت آزمون‌های قراردادی این بسته به معنی تست واقعی تونل نیست.

این ZIP **نصاب آماده روی سرور نیست**؛ قرارداد ساخت، نمونه‌ها و مرجع قابل‌اجرای رفتارهای مستقل از شبکه است. فایل‌های `reference/` و `tests/` برای جلوگیری از اختلاف پیاده‌سازی هستند و شبکه میزبان را تغییر نمی‌دهند.

## تصمیم‌های مهم

اطلاعات چت قدیمی فقط زمینه نیازها بود. **هیچ IP، پورت ویژه، اسکریپت قدیمی یا مهاجرتی در محصول تعریف نشده است.** برنامه نصب قدیمی GRE یا Port Manager را کشف و پاک نمی‌کند. تشخیص تداخل فعلی به‌صورت خواندنی همچنان لازم است.

ظاهر و رفتار برای ورودی و وضعیت یکسان باید یکسان باشد. متن‌ها، فایل‌ها و آزمون‌ها در این بسته تثبیت شده‌اند؛ کد تولیدی مدل‌های مختلف الزاماً بایت‌به‌بایت یکسان نیست. اگر نسخه اجرایی دقیقاً یکسان لازم باشد، پس از اولین ساخت تأییدشده باید همان commit و بسته release ثابت توزیع شود.

آمار ذخیره‌شده پس از ریبوت حفظ می‌شود. خاموشی ناگهانی می‌تواند آخرین نمونه ثبت‌نشده، حداکثر حدود یک دقیقه، را از بین ببرد؛ برنامه باید فاصله بدون داده را نشان دهد. آمار حجم، اندازه‌گیری لایه IP در نقطه حسابداری برنامه است و معادل دقیق صورتحساب دیتاسنتر نیست.

اجرای بررسی مستقل بسته:

```bash
python3 -m unittest discover -s tests -v
python3 tests/verify_package.py
```
